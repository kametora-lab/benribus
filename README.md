# 🚌 しまバスリンク (Amami Bus Link)

奄美大島の路線バス「しまバス」の時刻表を、スマートに検索・確認できるWebアプリケーションです。  
スマートフォンやPCにアプリとしてインストールできる PWA (Progressive Web App) に対応しています。

## 🌟 主な特徴

- **モバイル最適化UI**: スマートフォンの片手操作を考慮し、出発・到着バス停の選択エリアをコンパクトに横並び配置しています。
- **全便表示機能 (サイネージ連携)**: 各バス停入力欄の右端にあるリストアイコンをクリックすると、そのバス停のデジタルサイネージ（全便表示）時刻表を画面内の時刻表ビューに即座に表示します。
- **検索履歴の保存**: IndexedDBを活用し、最近検索したルートを最大5件までブラウザに自動保存。次回起動時にワンタップで再検索できます。
- **PWA対応**: 
  - スマートフォンやPCにインストール可能です。
  - サービスワーカー（Service Worker）によるキャッシュにより、オフライン時でも高速起動します。
  - アダンの実とレトロなバスをあしらった、奄美の海岸らしい可愛らしいカスタムアプリアイコンを採用しています。

## 🛠 技術スタック

- **フロントエンド**: HTML5, Vanilla CSS, JavaScript (ES6)
- **データストレージ**: IndexedDB (経路履歴の永続化)
- **PWA機能**: Service Worker API, Web App Manifest
- **インフラ/ホスティング**: 静的ファイルサーブに対応（任意のHTTPサーバーで動作）

## 🚀 ローカルでの実行方法

Node.js環境がある場合は、以下のコマンドを実行してローカルサーバーを起動できます。

```bash
# サーバーの起動
npx http-server -p 4173
```

ブラウザで `http://127.0.0.1:4173/` を開くことで動作確認が可能です。
